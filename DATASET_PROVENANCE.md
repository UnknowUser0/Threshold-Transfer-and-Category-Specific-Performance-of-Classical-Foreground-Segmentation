# CDnet2014 Dataset Provenance

The follow-up audit and pilot studies used the CDnet2014 dataset supplied locally by the user. The validated directory contained 11 benchmark categories and 53 sequences. Counting input frames from the supplied sequence directories yielded 159,278 frames. The local path is intentionally omitted from distributed files; dataset frames, ground-truth masks, and ROI masks are not included in the ZIP.

Dataset source: Y. Wang et al., “CDnet 2014: An expanded change detection benchmark dataset,” IEEE/CVF CVPR Workshops, 2014. https://openaccess.thecvf.com/content_cvpr_workshops_2014/W12/html/Wang_CDnet_2014_An_2014_CVPR_paper.html

The counts document the local directory used for this package build. They do not replace the benchmark's download instructions, license/terms, or an independent clean-room reproduction.
